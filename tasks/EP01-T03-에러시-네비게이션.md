## 설명
오류 발생 시 공연 상세로 돌아가야 하는데 공연 홈으로 돌아감

## 경로
공연 상세 > 예매하기 > 예매실패(오류)

## 작업 내용
- [ ] [FE] 에러 핸들러에서 redirect 경로를 공연 상세 페이지로 수정

## 현재 구현 상태 (FE)
- 주문 에러: `useOrderMutation`의 `onError`에서 바텀시트로 에러 메시지 표시
- 결제 실패: `/pay/fail?message=...&code=...`로 리다이렉트 후 메시지 표시
- **문제**: SSR에서 공연 상세 fetch 실패 시 `/home`으로 리다이렉트 (공연 상세 아님)
- ticket 앱에 전역 에러 핸들러 없음 (admin은 `useApiError`로 전역 처리 있음)
- **수정 방향**: 에러 시 `/events/:id`(공연 상세)로 리다이렉트 + 에러 토스트

## 수락 기준

- [ ] 예매 실패(오류) 시 공연 상세 페이지로 리다이렉트된다 (공연 홈이 아님)
- [ ] 리다이렉트 대상 URL에 해당 공연 ID가 포함되어 있다
- [ ] 공연 홈(`/`)으로 이동하는 케이스가 더 이상 발생하지 않는다

## 참고
FE only. 에러 핸들링 패턴 전체 점검할 기회
