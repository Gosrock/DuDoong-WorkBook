# 유저/인증 도메인 - 시나리오

## UC-U01: 카카오 회원가입

**Actor**: 비로그인 사용자
**선행조건**: 카카오 계정 보유

### 정상 플로우
1. 카카오 로그인 버튼 클릭
2. `GET /auth/oauth/kakao/link` → 카카오 인증 URL 획득
3. 카카오 인증 완료
4. `GET /auth/oauth/kakao?code={code}` → 카카오 신원 검증
5. 신규 유저 확인 → 회원가입 폼 표시
6. 이름, 이메일, (선택) 전화번호 입력
7. `POST /auth/oauth/kakao/register` → 유저 생성
8. 로그인 토큰 발급

### 예외 플로우
- 동일 계정 동시 가입 → 중복 가입 차단
- 카카오 신원 검증 실패 → 401

---

## UC-U02: 로그인

**Actor**: 기존 회원

### 정상 플로우
1. 카카오 인증 완료
2. 카카오 계정으로 기존 유저 조회
3. `POST /auth/oauth/kakao/login`
4. 로그인 토큰 발급, 마지막 로그인 시각 갱신

### 예외 플로우
- 탈퇴한 유저 → 로그인 불가 (403)
- 이용 정지된 유저 → 로그인 불가 (403)

---

## UC-U03: 토큰 갱신

**Actor**: 인증된 사용자 (액세스 토큰 만료)

### 정상 플로우
1. 액세스 토큰 만료 감지
2. `POST /auth/token/refresh` (리프레시 토큰 전달)
3. 리프레시 토큰 유효성 확인
4. 새 액세스 토큰 발급
5. 마지막 로그인 시각 갱신

### 예외 플로우
- 리프레시 토큰 만료 또는 미존재 → 401 → 재로그인 필요

---

## UC-U04: 회원 탈퇴

**Actor**: 로그인한 사용자

### 정상 플로우
1. `DELETE /auth/withdraw`
2. 로그인 토큰 무효화
3. 계정 탈퇴 처리, 프로필 마스킹
4. 카카오 계정 연동 해제

### 후처리
- 승인 대기 주문 → 자동 거부
- 이후 동일 카카오 계정으로 **재가입 가능** (기존 데이터와 분리됨)

---

## UC-U05: 로그아웃

**Actor**: 로그인한 사용자

### 정상 플로우
1. `POST /auth/logout`
2. 서버 측 로그인 토큰 무효화
3. 클라이언트 측 토큰 제거

---

## 문의 대응 가이드

### "로그인이 안 돼요"
1. 카카오 계정 상태 확인
2. 계정 상태 확인 (탈퇴 또는 이용 정지 상태이면 로그인 불가)
3. 탈퇴 후 재가입인 경우 → 새 계정으로 가입 안내

### "탈퇴했는데 다시 가입하고 싶어요"
- 동일 카카오 계정으로 재가입 가능 (기존 데이터와 분리)
- 이전 예매 내역/티켓은 복구 불가

### "다른 사람이 내 계정을 사용한 것 같아요"
- 카카오 계정 비밀번호 변경 후 재로그인 안내
