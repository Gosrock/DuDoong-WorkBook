# 통합 CS 대응 가이드

> 최종 수정: 2026-03-15

---

## 1. 문의 처리 워크플로우

```
접수 → 분류 → 1차 대응 → [해결] 또는 [에스컬레이션] → 종결
```

### 단계별 처리 기준

| 단계 | 담당 | 기준 |
|------|------|------|
| 접수 | CS 담당자 | 문의 채널(이메일, 카카오톡 등) 확인, 24시간 이내 1차 응답 |
| 분류 | CS 담당자 | 도메인(주문/티켓/공연/계정) + 유형(문의/불만/환불 요청) 분류 |
| 1차 대응 | CS 담당자 | 정책 기반 안내, 사용자 스스로 해결 가능한 경우 안내로 종결 |
| 에스컬레이션 | 개발팀/운영팀 | 정책 범위 초과, 시스템 오류 의심, 결제 이상 발생 시 |
| 종결 | CS 담당자 | 해결 확인 후 종결, 만족도 확인 (선택) |

---

## 2. 에스컬레이션 기준

### 1차 대응 (CS 담당자 직접 처리)

- 공지된 정책 내에서 안내 가능한 경우
- 사용자 조작 오류 (앱 재설치, 재로그인 등으로 해결 가능)
- 취소/환불 요청이 정책 범위 내인 경우
- FAQ에 해당하는 문의

### 2차 에스컬레이션 (개발팀 확인 필요)

아래 중 하나라도 해당하면 즉시 개발팀에 전달합니다.

- [ ] 결제 완료되었으나 티켓/주문이 생성되지 않음
- [ ] 중복 결제 또는 이중 청구 의심
- [ ] QR 코드가 정상 티켓임에도 입장 처리 불가
- [ ] 사용자 계정 데이터 이상 (잔액, 티켓 수량 등)
- [ ] 동일 오류가 다수 사용자에게 반복 발생
- [ ] 보안/개인정보 관련 문의 (해킹 의심, 타인 정보 접근 등)

### 에스컬레이션 전달 시 포함 정보

```
- 문의 접수 일시
- 사용자 식별 정보 (이메일 또는 사용자 ID, 이름 제외)
- 주문번호 / 티켓번호 (해당하는 경우)
- 문의 내용 요약
- CS 담당자 1차 확인 내용
```

## 3. 도메인별 FAQ

### 주문/결제

| 문의 유형 | 처리 방법 |
|-----------|-----------|
| **환불 요청** | 환불 정책 안내 → 취소 기한 내: 앱에서 직접 취소 안내 / 기한 초과: 주최자 승인 필요 안내 |
| **결제 실패** | 카드사 확인 요청 → 해결 안 되면 다른 결제 수단 안내 → 반복 실패 시 개발팀 에스컬레이션 |
| **중복 결제** | 결제 내역 확인 요청 → 실제 중복 확인 시 즉시 개발팀 에스컬레이션 (환불 처리) |
| **결제 완료인데 주문 없음** | 즉시 개발팀 에스컬레이션 (결제 데이터와 주문 불일치) |
| **영수증/증빙 요청** | 결제 확인 이메일 재발송 안내 또는 거래 내역 캡처 안내 |

### 티켓

| 문의 유형 | 처리 방법 |
|-----------|-----------|
| **QR 인식 안 됨** | 화면 밝기 최대 설정 안내 → 앱 재실행 안내 → 해결 안 되면 티켓 ID 직접 확인 요청 개발팀 전달 |
| **티켓 양도 문의** | 양도 가능 여부는 공연별 정책 확인 후 안내 (양도 불가 공연은 사전 안내 참고) |
| **티켓을 못 찾겠음** | 앱 로그인 상태 확인 → 주문 내역에서 티켓 조회 안내 → 여전히 없으면 주문번호로 확인 |
| **공연 취소 시 티켓 처리** | 주최자 취소 확인 후 자동 환불 일정 안내 |

### 공연

| 문의 유형 | 처리 방법 |
|-----------|-----------|
| **공연 정보 수정 문의** | 주최자 본인인지 확인 후 앱/대시보드에서 수정 방법 안내 |
| **공연 취소 처리** | 취소 절차 안내 → 예매자 환불 자동 처리 여부 설명 |
| **예매 오픈 문의** | 공연 상세 페이지의 오픈 일정 확인 안내 |
| **공연 날짜/장소 변경** | 주최자가 변경 후 예매자에게 안내 메일 발송 필요 설명 |

### 계정

| 문의 유형 | 처리 방법 |
|-----------|-----------|
| **로그인 안 됨** | 소셜 로그인 연동 확인 → 앱 재설치 안내 → 반복 시 개발팀 에스컬레이션 |
| **탈퇴 후 재가입** | 탈퇴 후 30일 경과 여부 확인 → 경과 시 동일 소셜 계정으로 재가입 안내 |
| **개인정보 변경 요청** | 앱 내 프로필 수정 안내 |
| **계정 정지/잠금** | 사유 안내 후 이의신청 절차 안내 |

## 4. 응답 템플릿

> 모든 응답은 정중하고 명확한 톤으로 작성합니다. 불필요한 사과 반복은 피하고, 해결 방향을 명확히 제시합니다.

### 환불 요청 (취소 기한 내)

```
안녕하세요, DuDoong 고객센터입니다.

문의해 주신 주문에 대해 안내드립니다.
현재 취소 가능 기간 내에 있어 앱에서 직접 취소하실 수 있습니다.

취소 방법:
1. 앱 > 주문 내역 접속
2. 해당 주문 선택
3. '주문 취소' 버튼 클릭

환불은 결제 수단에 따라 영업일 기준 3~5일 소요됩니다.
추가 문의사항이 있으시면 언제든지 연락 주세요.
```

### 결제 실패

```
안녕하세요, DuDoong 고객센터입니다.

결제 과정에서 불편을 드려 죄송합니다.
아래 사항을 확인해 주시면 대부분 해결됩니다.

1. 카드 한도 및 잔액 확인
2. 해외/온라인 결제 차단 여부 확인 (카드사 앱에서 설정 가능)
3. 다른 카드 또는 결제 수단으로 재시도

위 방법으로도 해결되지 않는다면 카드사 고객센터에 문의하시거나,
저희에게 다시 알려주시면 추가로 확인해 드리겠습니다.
```

### QR 인식 불가

```
안녕하세요, DuDoong 고객센터입니다.

QR 코드 인식이 되지 않아 불편을 드려 죄송합니다.
현장에서 아래 방법을 순서대로 시도해 주세요.

1. 화면 밝기를 최대로 설정
2. 앱을 완전히 종료 후 재실행
3. 인터넷 연결 상태 확인 후 재시도

위 방법으로도 해결되지 않는 경우, 티켓 하단의 예매 번호를
현장 스태프에게 직접 보여주시면 입장 처리가 가능합니다.
```

### 개발팀 에스컬레이션 시 사용자 응답

```
안녕하세요, DuDoong 고객센터입니다.

문의해 주신 사항을 확인하였습니다.
빠른 해결을 위해 담당 팀에 전달하여 처리 중입니다.
확인 후 [N 영업일] 이내에 답변 드리겠습니다.

불편을 드려 대단히 죄송합니다.
```

## 5. CS 대응 원칙

- **24시간 내 1차 응답**: 해결이 안 되더라도 접수 확인 메시지는 반드시 발송
- **명확한 다음 단계 안내**: "확인해 보겠습니다"로 끝내지 않고 처리 예정 일정 명시
- **개인정보 노출 주의**: 응답 메시지에 타 사용자 정보 절대 포함 금지
- **정책 외 약속 금지**: 확인되지 않은 환불/보상을 임의로 약속하지 않음
