# 호스트 도메인 - 시나리오

## UC-H01: 호스트 생성

**Actor**: 로그인한 유저
**선행조건**: 없음

### 정상 플로우
1. 이름(15자 이내), 소개 입력
2. 선택: 연락처, 프로필 이미지
3. 호스트 생성
4. 생성자 자동으로 MASTER 역할 부여

---

## UC-H02: 멤버 초대

**Actor**: 매니저 이상
**선행조건**: 호스트 존재

### 정상 플로우
1. 초대할 유저 선택
2. 동시 초대 충돌 방지 처리
3. 중복 가입 검증
4. 초대 대기 상태로 멤버 등록 (미승락 상태, GUEST 역할)
5. Slack 초대 알림 발송

### 예외 플로우
- 이미 가입된 유저 → 이미 가입된 멤버입니다
- GUEST 권한으로 초대 시도 → 초대 권한이 없습니다

---

## UC-H03: 초대 승락

**Actor**: 초대받은 본인

### 정상 플로우
1. 초대 내역 확인
2. 승락 → 활성 멤버로 전환
3. Slack 가입 완료 알림 발송

---

## UC-H04: 역할 변경

**Actor**: MASTER만

### 정상 플로우
1. 대상 멤버 선택
2. 새 역할 선택 (MANAGER ↔ GUEST)
3. 역할 변경
4. Slack 역할 변경 알림 발송

### 예외 플로우
- MASTER 역할 변경 시도 → **불가** (MASTER는 역할 변경 불가)
- MASTER가 아닌 사용자가 시도 → 권한이 없습니다

---

## UC-H05: 멤버 제거

**Actor**: MASTER만

### 정상 플로우 (2단계)
1. 대상 멤버 **비활성화**
2. 비활성 멤버 **제거**
3. Slack 추방 알림 발송

### 예외 플로우
- 활성 멤버 직접 제거 시도 → 먼저 비활성화 처리가 필요합니다

---

## UC-H06: Slack 알림 설정

**Actor**: 매니저 이상

### 정상 플로우
1. Slack 웹훅 URL 입력
2. 중복 URL 검증
3. 웹훅 등록
4. 이후 모든 호스트 이벤트 Slack 알림 수신

---

## 문의 대응 가이드

### "멤버를 초대했는데 안 보여요"
- 초대 후 상대방이 **승락**해야 활성 멤버로 표시됨

### "방장을 다른 사람으로 바꾸고 싶어요"
- MASTER 역할은 변경 불가 → 새 호스트 생성 필요

### "유료 티켓을 만들 수 없어요"
- 파트너 호스트인지 확인 → 제휴 문의 필요
