## 설명

## 경로
공연 상세 > 예매하기

## 작업 내용

- [ ] [BE] 예매 API 진입 시 재고 검증 강화
- [ ] [FE] 예매 버튼 진입 전 재고 상태 체크, 매진 시 차단 UI

## 현재 구현 상태 (FE)
- 공연 상세 Tickets 컴포넌트: `isQuantityLeft === false`이면 회색 "매진" 태그 표시
- SelectTicket 드롭다운: 매진 티켓은 `disabled`로 선택 불가
- **문제**: "예매하기" 버튼(Remote 컴포넌트)은 매진과 무관하게 항상 활성화됨
  - `isOutdated`(지난 공연)일 때만 비활성화
  - 모든 티켓이 매진이어도 예매하기 → 바텀시트 → 드롭다운에서 전부 disabled → 진행 불가
- **수정 방향**: Remote 컴포넌트에서 전체 매진 시 버튼 비활성화 + "매진" 텍스트

## 수락 기준

- [ ] 매진된 티켓의 예매 버튼이 비활성화(disabled)되고 "매진" 표시가 노출된다
- [ ] 매진 상태에서 예매 API 호출 시 재고 부족 에러 응답이 반환된다 (200 아님)
- [ ] 매진 상태에서 예매 플로우 다음 단계로 진입이 차단된다
