# 장바구니(Cart) 도메인 정책

## 기본 규칙

| 규칙 | 내용 |
|------|------|
| 유저당 장바구니 | **1개** (새로 담으면 기존 장바구니 덮어쓰기) |
| 담을 수 있는 티켓 | **단일 티켓 종류**만 (다른 종류 불가) |
| 장바구니 자동 삭제 | 주문 생성 시 자동 삭제 (`CreateOrderEvent` 처리) |

---

## 장바구니 생성 시 검증 (7가지)

| # | 검증 항목 | 실패 시 |
|---|----------|--------|
| 1 | 이벤트가 `OPEN` 상태인지 | 장바구니 생성 불가 |
| 2 | 티켓 판매 시간 내인지 (`sale_start_at` ~ `sale_end_at`) | 판매 기간 아님 |
| 3 | 재고가 충분한지 | 재고 부족 |
| 4 | 1인당 구매 제한 이내인지 | 구매 제한 초과 |
| 5 | 옵션 답변이 필수 옵션을 모두 포함하는지 | 필수 옵션 누락 |
| 6 | 옵션 답변이 유효한 옵션 그룹에 속하는지 | 유효하지 않은 옵션 |
| 7 | 티켓이 판매 가능(`sellable`) 상태인지 | 판매 중지됨 |

---

## UseCase

| UseCase | 설명 |
|---------|------|
| `CreateCartUseCase` | 장바구니 생성 (기존 장바구니 덮어쓰기) |

### 플로우
```
관객이 티켓 선택 + 수량 + 옵션 답변 입력
    → POST /carts
    → 7가지 검증
    → Cart 생성 (기존 Cart 있으면 덮어쓰기)
    → cartId 반환
```

---

## 장바구니 구조

```
Cart (유저당 1개)
  └── CartLineItem (1개, 단일 티켓 종류)
       └── CartOptionAnswer (옵션 답변들)
```

### 핵심 메서드
- `isNeedPaid()`: 결제 필요 여부 (무료가 아닌 경우)
- 장바구니 데이터는 주문 생성의 입력으로 사용

---

## 문의 대응 가이드

### "장바구니에 담았는데 사라졌어요"
- 다른 티켓을 담으면 기존 장바구니가 **덮어쓰기** 됨
- 주문 완료 시 자동 삭제됨
