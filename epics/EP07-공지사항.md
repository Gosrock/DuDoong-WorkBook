# EP07: 공지사항 기능

## 개요

두둥 서비스 전체 공지사항. 관리자(ADMIN)가 작성하고, 모든 유저가 확인할 수 있는 공지 기능.

## 배경

- 서비스 점검, 정책 변경, 신기능 안내 등을 전달할 채널이 없음
- 현재는 카카오 비즈채널 1:1 채팅으로만 소통 → 일방향 공지 불가
- EP06 알림톡 토큰 BM 런칭 시 가격/정책 안내에도 필요

## 기능 범위

### 관리자 (어드민)
- 공지사항 CRUD (생성, 조회, 수정, 삭제)
- Toast UI Editor (WYSIWYG) 로 본문 작성 — **기존 호스트 어드민 에디터 재활용**
- 이미지 첨부 (기존 S3 presigned URL 방식 그대로)
- 공지 상단 고정 (pinned)
- 공지 노출/숨김 토글

### 유저 (두둥앱)
- 공지사항 목록 조회
- 공지사항 상세 조회 (Toast UI Viewer로 렌더링)
- 상단 고정 공지 우선 노출

## 데이터 모델

### Notice 엔티티

```kotlin
@Entity
@Table(name = "notice")
open class Notice(
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    val id: Long = 0L,

    @Column(nullable = false, length = 200)
    var title: String,

    @Column(nullable = false, columnDefinition = "TEXT")
    var content: String,        // HTML (Toast UI Editor 출력)

    @Column(nullable = false)
    var pinned: Boolean = false, // 상단 고정

    @Column(nullable = false)
    var visible: Boolean = true, // 노출 여부

    @Column(nullable = false)
    val createdAt: LocalDateTime = LocalDateTime.now(),

    @Column(nullable = false)
    var updatedAt: LocalDateTime = LocalDateTime.now(),

    @Column(nullable = false)
    val createdBy: Long,         // 작성자 userId (ADMIN)
)
```

### DDL

```sql
CREATE TABLE notice (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    title       VARCHAR(200) NOT NULL,
    content     TEXT NOT NULL,
    pinned      BOOLEAN NOT NULL DEFAULT FALSE,
    visible     BOOLEAN NOT NULL DEFAULT TRUE,
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    created_by  BIGINT NOT NULL
);

CREATE INDEX idx_notice_visible_pinned ON notice(visible, pinned DESC, created_at DESC);
```

## API 설계

### 공개 API (유저용)

#### `GET /api/v1/notices`
공지사항 목록 조회 (visible=true만, pinned 우선 → 최신순)

**Request**
```
GET /api/v1/notices?page=0&size=20
```

**Response**
```json
{
  "content": [
    {
      "id": 1,
      "title": "두둥 알림톡 토큰 서비스 오픈 안내",
      "pinned": true,
      "createdAt": "2026-03-22T10:00:00"
    }
  ],
  "page": 0,
  "size": 20,
  "totalElements": 5
}
```

**접근 권한**: permitAll (비로그인도 조회 가능)

#### `GET /api/v1/notices/{noticeId}`
공지사항 상세 조회

**Response**
```json
{
  "id": 1,
  "title": "두둥 알림톡 토큰 서비스 오픈 안내",
  "content": "<h2>안녕하세요</h2><p>두둥에서 알림톡 토큰...</p>",
  "pinned": true,
  "createdAt": "2026-03-22T10:00:00",
  "updatedAt": "2026-03-22T10:00:00"
}
```

**접근 권한**: permitAll

---

### 관리자 API (어드민용)

#### `GET /internal-api/v1/notices`
전체 공지 목록 (visible/hidden 포함)

**접근 권한**: ADMIN, SUPER_ADMIN

#### `POST /internal-api/v1/notices`
공지사항 생성

**Request**
```json
{
  "title": "서비스 점검 안내",
  "content": "<p>3월 25일 02:00~04:00 점검 예정입니다.</p>",
  "pinned": false,
  "visible": true
}
```

**접근 권한**: ADMIN, SUPER_ADMIN

#### `PUT /internal-api/v1/notices/{noticeId}`
공지사항 수정

**Request**
```json
{
  "title": "서비스 점검 안내 (수정)",
  "content": "<p>3월 25일 02:00~06:00으로 연장되었습니다.</p>",
  "pinned": true,
  "visible": true
}
```

**접근 권한**: ADMIN, SUPER_ADMIN

#### `DELETE /internal-api/v1/notices/{noticeId}`
공지사항 삭제

**접근 권한**: SUPER_ADMIN

#### `POST /internal-api/v1/notices/image`
공지 이미지 업로드 (S3 presigned URL 발급)

**Request**
```json
{
  "imageFileExtension": "PNG"
}
```

**Response**
```json
{
  "presignedUrl": "https://s3.../upload?...",
  "url": "https://asset.dudoong.com/notices/..."
}
```

**접근 권한**: ADMIN, SUPER_ADMIN

## 프론트엔드 구현

### 어드민 앱 (DuDoong-Front/apps/admin)

| 화면 | 설명 | 재활용 |
|------|------|--------|
| 공지 목록 | 테이블 (제목, 날짜, 고정여부, 노출여부) | antd Table |
| 공지 작성/수정 | Toast UI Editor (WYSIWYG) | **EventDetailInfo.tsx 패턴 그대로** |
| 이미지 업로드 | S3 presigned URL | 기존 uploadImageHandler 재활용 |

### 유저 앱 (DuDoong-Front/apps/ticket)

| 화면 | 설명 | 재활용 |
|------|------|--------|
| 공지 목록 | 카드/리스트 형태 | 기존 UI 컴포넌트 |
| 공지 상세 | Toast UI Viewer | **MdViewer.tsx 그대로** |

### 재활용 포인트

1. **Toast UI Editor** (`@toast-ui/react-editor`) — admin에 이미 설치됨
2. **S3 이미지 업로드** — `EventApi.POST_EVENT_IMAGE` 패턴 복사
3. **Toast UI Viewer** (`MdViewer.tsx`) — ticket앱에 이미 있음
4. **antd** — admin에서 테이블/폼 UI용으로 이미 사용 중

## 의사결정

| 결정 | 내용 | 이유 |
|------|------|------|
| Toast UI Editor 재활용 | 호스트 어드민의 에디터 그대로 사용 | 이미 설치/검증됨, S3 이미지 업로드도 동일 패턴 |
| 공지 API는 permitAll | 비로그인 유저도 조회 가능 | 서비스 점검 안내 등은 로그인 없이도 봐야 함 |
| 삭제는 SUPER_ADMIN만 | 실수로 삭제 방지 | ADMIN은 숨김(visible=false)으로 처리 |
| 별도 도메인(notice) | event/host와 독립 | 서비스 레벨 공지이므로 기존 도메인과 무관 |
