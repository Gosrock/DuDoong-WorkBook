## 태그 설계 제안

### 유형 태그 (공연명 키워드 기반)
`정기공연` / `연합공연` / `합동공연` / `단독공연` / `쇼케이스` / `페스티벌` / `연주회` / `라이브`

### 장르 태그 (수동 분류 필요)
현재 DB에 장르 컬럼 없어 자동 분류 불가. 이벤트 생성 시 장르 선택 필드 추가 제안.
예: 록/밴드, 인디, J-Pop, 힙합, 어쿠스틱 등

### 지역 태그 (장소 기반)
`홍대` / `합정` / `신촌` / `강남` / `기타`
장소명 정규화 후 지역 자동 매핑 가능
