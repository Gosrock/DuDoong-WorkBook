# 쿠폰(Coupon) 도메인 정책

> 현재 프로덕션에서 쿠폰 캠페인 **0건** (기능 구현 완료, 미사용 상태)

## 할인 유형

| 유형 | 코드 | 제약 |
|------|------|------|
| 정액 할인 | `AMOUNT` | 할인액 고정 |
| 정률 할인 | `PERCENTAGE` | 최대 100% |

## 적용 대상

| 대상 | 코드 | 설명 |
|------|------|------|
| 전체 | `ALL` | 모든 이벤트 (기본값) |
| 특정 | `SUB` | 특정 이벤트만 |

---

## 발급 규칙

### 3중 제약
1. **발급 기간**: `start_at` ~ `end_at` 내에서만 발급
2. **재고**: `remainingAmount` 차감 관리
3. **유효 기간**: `validTerm` (일 단위) - 발급일로부터 N일간 유효

### 동시성 제어
- **Redisson 분산락** + 1인 1쿠폰 중복 발급 방지

### 기타 규칙
- 쿠폰 코드: 시스템 전체 유일성 보장
- **최소 주문 금액**: 기본값 10,000원, 할인액이 초과하면 예외
- 쿠폰 캠페인 생성: **SUPER_ADMIN 전용** API

---

## 쿠폰 사용/복구

| 시점 | 동작 |
|------|------|
| 주문 생성 시 | 쿠폰 적용 (`usage_status → true`) |
| 주문 취소/환불 시 | 자동 복구 (`usage_status → false`) |

### 적용 가능 조건
- 선착순(`FIRST_COME`) 주문에만 적용 가능
- 결제가 필요한 주문 (`isNeedPaid = true`)
- 최소 주문금액 충족
