# 관객 예매 플로우

## 1. 인증 (카카오 로그인)

```
카카오 로그인 버튼
  → GET /auth/oauth/kakao/link (인증 URL 획득)
  → 카카오 인증 완료
  → GET /auth/oauth/kakao?code={code} (토큰 교환)
  → 신규 여부 확인
      ├── 신규 → POST /auth/oauth/kakao/register (회원가입)
      └── 기존 → POST /auth/oauth/kakao/login (로그인)
  → Recoil authState 업데이트 + 쿠키 저장
```

---

## 2. 이벤트 탐색 & 예매

```
/home                      → 이벤트 목록 (검색/필터)
  ↓
/events/{eventId}          → 이벤트 상세 + 티켓 선택
  ↓  (로그인 필요)
/events/{eventId}/book/option  → 옵션 선택 (없으면 자동 스킵)
  ↓  POST /carts (장바구니 생성 → cartId)
/events/{eventId}/book/order   → 주문 확인 + 결제 방식 선택
```

---

## 3. 결제 분기

### 유료 티켓 (PRICE_TICKET)
```
TossPayments SDK 결제
  → /pay/confirm
  → POST /orders/{uuid}/confirm
  → /pay/success
```

### 두둥 티켓 (DUDOONG_TICKET)
```
무통장입금 계좌 안내 표시
  → POST /orders/
  → 승인 대기 상태
  → 호스트가 승인 후 티켓 발급
```

### 무료 티켓 (FREE_TICKET + 선착순)
```
POST /orders/{uuid}/free
  → 즉시 확정
  → /pay/success
```

---

## 4. 예매 확인 & QR 입장

```
/history                   → GET /orders/?showing=true (예매 목록)
/history/{orderId}         → GET /orders/{uuid}/tickets (티켓 목록)
/ticket/{id}               → GET /issuedTickets/{uuid}
                           → QR 코드 렌더링 (UUID 기반)
                           → 입장 상태별 색상:
                              - 입장 전: 검정
                              - 입장 완료: 회색
```
