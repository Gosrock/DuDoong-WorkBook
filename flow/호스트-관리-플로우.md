# 호스트 관리 플로우

## 라우팅 구조 (admin 앱)

```
/                              → 홈 (호스트 목록)
/new/hosts                     → 호스트 생성
/new/events                    → 이벤트 생성

/hosts/{hostId}/dashboard      → 호스트 대시보드
/hosts/{hostId}/member         → 멤버 관리
/hosts/{hostId}/info           → 호스트 정보
/hosts/{hostId}/alliance       → 제휴 정보
/hosts/{hostId}/slack          → Slack 연동 설정

/events/{eventId}/dashboard    → 이벤트 대시보드 (통계)
/events/{eventId}/detail       → 이벤트 상세 정보
/events/{eventId}/info         → 이벤트 기본 정보
/events/{eventId}/tickets      → 티켓 상품 관리
/events/{eventId}/options      → 옵션 그룹 관리
/events/{eventId}/guests       → 예매자 관리
/events/{eventId}/qr           → QR 스캐너
```

---

## 이벤트 생성 7단계

```
1. 호스트 생성 (또는 기존 호스트 선택)
2. 이벤트 생성 (이름, 시간, 러닝타임 설정)
3. 장소 설정 (카카오 맵 검색)
4. 상세 설정 (포스터 업로드 → S3 Presigned URL, 본문 작성)
5. 티켓 생성 (PayType + ApproveType 선택, 가격/수량/판매기간 설정)
6. 옵션 생성 및 티켓에 적용
7. PATCH /events/{id}/open (이벤트 공개)
```

## 예매자(게스트) 관리

> 출처: [두둥 공연 관리하기](../public-notion/두둥-공연-관리하기.md)

### 승인 대기 탭
```
GET /events/{id}/orders?orderStage=APPROVE_WAITING
  → POST /events/{id}/orders/{uuid}/approve  (승인)
  → POST /events/{id}/orders/{uuid}/refuse   (거절)
```

### 완료 탭
```
GET /events/{id}/orders?orderStage=CONFIRMED
  → POST /events/{id}/orders/{uuid}/cancel   (취소)
```

### 예매 티켓 조회
- 발급된 티켓 목록 조회
- 입장 여부 확인

## QR 입장 처리

```
카메라 QR 스캔 → UUID 추출
  → PATCH /events/{eventId}/issuedTickets/{uuid}
  → 입장 상태 변경: ENTRANCE_INCOMPLETE → ENTRANCE_COMPLETED
```

**QR 스캐너 모드**: 풀스크린 / 모바일 / 일반 / 웹 4가지 UI 지원
