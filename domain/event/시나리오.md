# 이벤트 도메인 - 시나리오

## UC-E01: 이벤트 생성

**Actor**: 호스트 매니저 이상
**선행조건**: 호스트 생성 완료

### 정상 플로우
1. 호스트가 이벤트 이름, 시작일시, 러닝타임을 입력
2. 시스템이 종료시간 자동 계산 (시작일시 + 러닝타임)
3. 이벤트 생성 (준비 중 상태)
4. Slack 알림 발송

### 예외 플로우
- 호스트 권한 부족 → 403

## UC-E02: 이벤트 기본 정보 수정

**Actor**: 호스트 매니저 이상

### 정상 플로우
1. 이벤트가 준비 중 상태인지 확인
2. 이름/시작일시/러닝타임 수정
3. 이벤트 변경 알림 발송

### 예외 플로우
- 오픈 상태에서 기본정보 수정 시도 → 오픈된 공연의 기본 정보는 수정할 수 없습니다

## UC-E03: 이벤트 상세 정보 수정

**Actor**: 호스트 매니저 이상

### 정상 플로우
1. 상세 설명 또는 이미지 수정
2. **오픈 상태에서도 수정 가능**
3. 이벤트 변경 알림 발송

### 핵심 규칙
- 포스터 이미지: S3 Presigned URL로 업로드
- 본문: 길이 제한 없음

---

## UC-E04: 이벤트 오픈

**Actor**: 호스트 매니저 이상
**선행조건**: 준비 중 상태

### 정상 플로우
1. 오픈 조건 5가지 검증:
   - 기본 정보 입력 완료
   - 장소 정보 입력 완료
   - 상세 정보 입력 완료
   - 티켓 항목 최소 1개 등록
   - 시작일시가 현재 시각 이후
2. 오픈 상태로 전환
3. 이벤트 상태 변경 알림 발송

### 예외 플로우
- 이미 오픈 상태 → 이미 오픈된 공연입니다
- 시작일시가 이미 지남 → 공연 시작 시각이 만료되어 오픈할 수 없습니다
- 필수 정보 미입력 → 오픈 불가

## UC-E05: 이벤트 삭제

**Actor**: 호스트 매니저 이상

### 정상 플로우
1. 삭제 가능 상태 확인 (준비 중 상태만)
2. 발급 티켓 존재 여부 확인
3. 삭제 처리 (데이터 보존, 목록에서만 제거)
4. 이벤트 삭제 알림 발송

### 예외 플로우
- 오픈 상태에서 삭제 → 오픈된 공연은 삭제할 수 없습니다
- 이미 삭제됨 → 이미 삭제된 공연입니다
- 발급 티켓 존재 → 삭제 불가

## 이벤트 수정 가능 범위 매트릭스

| 항목 | 준비 중 | 오픈 | 정산 중 | 종료 |
|------|:-------:|:----:|:-------:|:----:|
| 이름 | O | X | X | X |
| 시작시간 | O | X | X | X |
| 러닝타임 | O | X | X | X |
| 장소 | O | X | X | X |
| 상세 설명 | O | O | X | X |
| 이미지 | O | O | X | X |
| 티켓 추가 | O | O | X | X |
| 티켓 수정 | O | 제한적 | X | X |
| 삭제 | O | X | X | X |

### 오픈 상태 티켓 수정 세부 규칙

| 항목 | 가능 여부 | 비고 |
|------|:---------:|------|
| 티켓 새로 추가 | O | 새 티켓 종류 추가 가능 |
| 티켓 이름/설명 수정 | X | 이미 구매된 티켓에 영향 |
| 티켓 가격 수정 | X | 가격 불일치 방지 |
| 티켓 재고 증가 | O | 추가 판매 허용 |
| 티켓 재고 감소 | X | 판매된 수량보다 적어질 수 있음 |
| 티켓 삭제 | X | 발급된 티켓 존재 가능 |
| 티켓 옵션 추가/수정/삭제 | X | 옵션 정합성 |

## 비허용 상태 전이 시 에러 메시지

| 시도 | 에러 메시지 |
|------|------------|
| PREPARING → CALCULATING | 오픈되지 않은 공연은 정산할 수 없습니다 |
| PREPARING → CLOSED | 오픈되지 않은 공연은 종료할 수 없습니다 |
| OPEN → CLOSED (직행) | 정산 과정을 거쳐야 종료할 수 있습니다 |
| CALCULATING → OPEN | 정산 중인 공연은 다시 오픈할 수 없습니다 |
| CLOSED → (any) | 종료된 공연의 상태를 변경할 수 없습니다 |
| OPEN → DELETED | 오픈된 공연은 삭제할 수 없습니다 |
| DELETED → (any) | 이미 삭제된 공연입니다 |
