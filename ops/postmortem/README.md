# 포스트모템 (Postmortem)

장애 발생 후 원인 분석과 재발 방지를 기록합니다.
"누구 잘못"이 아니라 **시스템 개선**이 목적입니다.

## 파일 형식

`PM-{번호}-{제목}.md` (예: `PM-001-결제API-타임아웃.md`)

## 템플릿

```markdown
## PM-XXX: 제목

- **일시**: YYYY-MM-DD HH:MM ~ HH:MM (지속시간)
- **영향**: 영향받은 사용자/기능/건수
- **심각도**: Critical / Major / Minor
- **감지 방법**: 어떻게 알게 되었는지 (모니터링? 유저 신고?)

### 타임라인
| 시각 | 내용 |
|------|------|
| HH:MM | 장애 감지 |
| HH:MM | 원인 파악 |
| HH:MM | 조치 완료 |

### 원인
근본 원인 (Root Cause) 설명

### 조치
긴급 대응으로 한 것

### 재발 방지
- [ ] 액션 아이템 1 (담당자, 기한)
- [ ] 액션 아이템 2 (담당자, 기한)

### 배운 점
이번 장애에서 배운 것
```
