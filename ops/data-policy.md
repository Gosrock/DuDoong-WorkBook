## 2. 회원 탈퇴 시 데이터 처리

### 처리 순서

```
탈퇴 요청 → 즉시 처리 → 30일 보관 → 완전 삭제
```

### 즉시 처리 (탈퇴 시점)

| 항목 | 처리 방식 |
|------|-----------|
| 프로필 정보 (닉네임, 이미지) | 즉시 마스킹 처리 ("탈퇴한 사용자"로 대체) |
| 소셜 로그인 연동 | 즉시 해제 |
| 마케팅 수신 동의 | 즉시 철회 처리 |
| 서비스 노출 정보 | 즉시 비노출 처리 |

### 30일 보관 후 삭제

| 항목 | 보관 이유 |
|------|-----------|
| 계정 식별 정보 | 탈퇴 철회 요청 대응, 부정 이용 방지 |
| 접속 기록 | 법령 보관 의무 (3개월) 와 조율하여 처리 |

### 법령에 따라 별도 보관

| 항목 | 보관 기간 | 처리 방식 |
|------|-----------|-----------|
| 주문/결제 기록 | 5년 | 계정 정보와 분리 보관, 법령 의무 종료 후 삭제 |
| 분쟁/환불 기록 | 3년 | 계정 정보와 분리 보관 |

> 탈퇴 후에도 법령에 따라 일부 데이터는 의무적으로 보관됩니다. 이는 탈퇴 안내 시 사용자에게 고지합니다.

## 3. 데이터 삭제 요청 대응 절차

사용자가 개인정보 삭제를 요청하는 경우 아래 절차를 따릅니다.

### 처리 흐름

```
삭제 요청 접수 → 본인 확인 → 법령 보관 의무 검토
→ 삭제 가능 데이터 처리 → 결과 안내 (10일 이내)
```

### 단계별 처리 기준

| 단계 | 내용 |
|------|------|
| 접수 | 고객센터 또는 앱 내 개인정보 삭제 요청 접수 |
| 본인 확인 | 계정 소유자 여부 확인 (소셜 로그인 인증) |
| 법령 검토 | 보관 의무가 있는 데이터 여부 확인 |
| 삭제 처리 | 보관 의무 없는 데이터 즉시 삭제, 의무 있는 데이터는 사유 안내 |
| 결과 안내 | 처리 결과를 요청일로부터 10일 이내 이메일로 안내 |

### 삭제 요청 불가 항목 안내

아래 항목은 법령에 따라 의무 보관 기간 동안 삭제가 불가합니다.

- 주문/결제 기록 (전자상거래법, 5년)
- 분쟁 처리 기록 (전자상거래법, 3년)
- 접속 로그 (통신비밀보호법, 3개월)

사용자에게는 다음과 같이 안내합니다.

> "해당 정보는 [관련 법령명]에 따라 [보관 기간] 동안 의무적으로 보관해야 합니다.
> 보관 기간 종료 후 즉시 삭제 처리됩니다."

## 4. 데이터 접근 통제

| 데이터 유형 | 접근 권한 |
|-------------|-----------|
| 사용자 개인정보 | 담당 개발자 + 운영팀 최소 인원 |
| 결제/주문 데이터 | 담당 개발자 + 정산 담당자 |
| 접속 로그 | 보안/개발팀 |
| 탈퇴 보관 데이터 | 개인정보 보호 담당자 |

---

## 5. 데이터 처리 원칙

- **최소 수집**: 서비스 제공에 필요한 최소한의 개인정보만 수집
- **목적 외 사용 금지**: 수집 목적 이외의 용도로 개인정보 사용 금지
- **안전한 보관**: 개인정보는 암호화하여 보관
- **접근 최소화**: 담당자 외 개인정보 접근 제한
- **파기 확인**: 보관 기간 종료 후 파기 절차 기록 유지

> 개인정보 처리 관련 전체 정책은 서비스 내 개인정보 처리방침을 참고하세요.
