# 장바구니(Cart) 도메인 정책

## 기본 규칙

| 규칙 | 내용 |
|------|------|
| 유저당 장바구니 | **1개** (새로 담으면 기존 장바구니 덮어쓰기) |
| 담을 수 있는 티켓 | **단일 티켓 종류**만 (다른 종류 혼합 불가) |
| 장바구니 자동 삭제 | 주문 생성 시 자동 삭제 |

---

## 장바구니 생성 시 검증 규칙

관객이 티켓을 장바구니에 담으면, 시스템은 다음 **7가지 조건**을 확인합니다. 주문 전 단계에서 미리 걸러내어 불필요한 결제 시도를 방지합니다.

### 1. 한 종류의 티켓만 담았는가?

장바구니에는 **한 가지 종류의 티켓**만 담을 수 있습니다. "일반석"과 "VIP석"을 동시에 담는 것은 불가능합니다. 다른 종류를 원하면 별도로 주문해야 합니다.

### 2. 옵션 답변이 올바른가?

티켓에 옵션이 있는 경우(예: "사이즈 선택", "소속 입력"), 각 답변이 유효한지 확인합니다.

- **객관식**: 미리 정의된 선택지 중 하나를 골랐는지 (예: S/M/L/XL 중 하나)
- **Y/N**: "예" 또는 "아니오" 중 하나인지
- **주관식**: 자유 텍스트이므로 별도 검증 없이 통과

### 3. 모든 필수 옵션에 답변했는가?

티켓에 연결된 옵션 그룹이 3개인데 2개만 답변했다면 거부됩니다. 모든 옵션 그룹에 빠짐없이 답변해야 합니다.

### 4. 공연이 오픈 상태인가?

해당 이벤트가 "진행중(OPEN)" 상태여야 합니다.

### 5. 공연 시작 전인가?

현재 시각이 공연 시작 시간보다 이전이어야 합니다.

### 6. 재고가 남아있는가?

담으려는 수량만큼 재고가 있어야 합니다.

### 7. 1인당 구매 제한을 넘지 않는가?

이전에 이미 구매한 수량 + 장바구니 수량이 호스트가 설정한 구매 제한을 넘으면 안 됩니다.

## 장바구니 관련 에러 메시지

| 사용자에게 보이는 상황 | 원인 | 대응 |
|----------------------|------|------|
| 여러 종류 티켓을 담으려 할 때 | 한 종류만 담을 수 있는 정책 | 한 종류씩 따로 주문 안내 |
| 옵션 답변이 거부될 때 | 객관식에서 유효하지 않은 값 선택 | 옵션 다시 선택 안내 |
| 옵션을 다 선택하지 않았을 때 | 필수 옵션 누락 | 모든 옵션 답변 후 재시도 |

---

## 장바구니 흐름

```
관객이 티켓 선택 + 수량 + 옵션 답변 입력
    → 7가지 검증
    → 장바구니 생성 (기존 장바구니 있으면 덮어쓰기)
    → 장바구니 ID 반환 (주문 생성에 사용)
```

---

## 장바구니 구조

```
장바구니 (유저당 1개)
  └── 장바구니 항목 (1개, 단일 티켓 종류)
       └── 옵션 답변들
```

장바구니 데이터는 주문 생성의 입력으로 사용되며, 주문 생성 후 자동으로 삭제됩니다.

---

## 문의 대응 가이드

### "장바구니에 담았는데 사라졌어요"
- 다른 티켓을 담으면 기존 장바구니가 **덮어쓰기** 됩니다.
- 주문 완료 시 자동 삭제됩니다.
