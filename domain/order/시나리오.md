# 주문/결제 도메인 - 시나리오

## UC-O01: 유료 티켓 주문 (카드 결제)

**Actor**: 로그인한 관객
**선행조건**: 이벤트 오픈 상태, 선착순 판매, 유료 티켓

### 정상 플로우
1. 관객이 장바구니에서 "결제하기" 선택
2. 시스템이 6가지 검증 수행 (이벤트 상태, 재고, 구매제한 등)
3. 동시 주문 충돌 방지 처리 (동일 사용자 중복 요청 차단)
4. 주문 생성 → 결제 대기 상태
5. 토스페이먼츠 SDK 결제 진행
6. 결제 성공 → `POST /orders/{uuid}/confirm`
7. PG 결제 금액과 주문 금액 일치 검증
8. 주문 확정, 주문 완료 이벤트 발행
9. 발급 티켓 자동 생성 (구매 수량만큼)

### 예외 플로우
- 재고 부족 → 주문 생성 실패
- 결제 금액 불일치 → 결제 실패, 보상 트랜잭션 실행
- 결제 시간 초과 → 배치에서 만료 처리

## UC-O02: 무료 티켓 주문 (선착순)

**Actor**: 로그인한 관객
**선행조건**: 이벤트 오픈 상태, 무료 티켓, 선착순 판매

### 정상 플로우
1. 관객이 장바구니에서 "예매하기" 선택
2. 검증 수행
3. 주문 생성 → 결제 대기 상태
4. `POST /orders/{uuid}/free` 호출
5. **즉시 확정**
6. 주문 완료 이벤트 발행 → 티켓 자동 발급

## UC-O03: 두둥 티켓 주문 (무통장입금 + 승인)

**Actor**: 로그인한 관객
**선행조건**: 이벤트 오픈 상태, 두둥 티켓, 승인형 판매

### 정상 플로우
1. 관객이 주문 생성
2. 검증 수행 (승인 대기 주문 포함 보수적 재고 검사)
3. 주문 생성 → 승인 대기 상태
4. 무통장입금 계좌 정보 표시 (호스트 계좌)
5. 관객이 호스트 계좌로 입금
6. 호스트가 입금 확인 후 `POST /events/{id}/orders/{uuid}/approve`
7. 주문 승인 완료, 주문 완료 이벤트 발행

### 주문 승인 알림
> 출처: [두둥 티켓 종류 및 유의사항](../public-notion/두둥-티켓-종류-및-유의사항.md)
- Slack 웹훅으로 주문 생성 알림 수신 가능

## UC-O04: 사용자 환불

**Actor**: 주문한 관객 본인
**선행조건**: 주문이 확정 또는 승인 상태, 이벤트 시작 전

### 정상 플로우
1. 관객이 마이페이지에서 "환불하기" 선택
2. 본인 주문인지 확인
3. 환불 가능 기간 확인 (이벤트 시작 전까지)
4. 환불 처리, 주문 취소 이벤트 발행
5. 보상 처리: 쿠폰 복구, 티켓 취소, 재고 복구
6. 유료 주문: PG 환불 비동기 처리

### 예외 플로우
- 이벤트 시작 후 → 환불 불가
- 다른 사용자의 주문 → 권한 없음
- 두둥 티켓: 시스템 환불 후 **호스트에게 별도 연락하여 계좌 전달 필요**

## UC-O05: 관리자 주문 취소

**Actor**: 호스트 매니저 이상
**선행조건**: 주문이 확정 또는 승인 상태

### 정상 플로우
1. 호스트가 게스트 관리에서 "취소" 선택
2. 주문 취소 처리, 주문 취소 이벤트 발행
3. 보상 처리 동일 (쿠폰 복구, 티켓 취소, 재고 복구, PG 환불)

---

## UC-O06: 관리자 주문 거절 (승인형)

**Actor**: 호스트 매니저 이상
**선행조건**: 주문이 승인 대기 상태

### 정상 플로우
1. 호스트가 "거절" 선택
2. 주문 취소 처리
3. 재고 복구

### 핵심 차이
- 거절은 주문 취소 이벤트를 발행하지 **않음** (PG 환불 불필요)
- 두둥 티켓이므로 PG 결제가 없었음

## UC-O07: 쿠폰 적용 주문

**Actor**: 로그인한 관객
**선행조건**: 유효한 쿠폰 보유, 선착순 유료 티켓

### 정상 플로우
1. 주문 생성 시 쿠폰 ID 전달
2. 쿠폰 유효성 검증:
   - 발급 기간 내
   - 유효기간 미만료
   - 미사용 상태
   - 최소 주문금액 충족
3. 할인 금액 계산: 결제금액 = 공급가액 - 할인금액
4. 0원이면 무료 주문으로 처리

### 예외 플로우
- 쿠폰 유효기간 만료 → 적용 불가
- 최소 주문금액 미달 → 적용 불가
- 승인형 주문에 쿠폰 적용 불가

## 문의 대응 가이드

### "환불이 안 돼요"
1. 이벤트 시작시간 확인 → 시작 후에는 환불 불가
2. 주문 상태 확인 → 확정/승인 상태만 환불 가능
3. 두둥 티켓이면 호스트에게 직접 환불 요청 안내

### "주문이 자동으로 취소됐어요"
1. 결제 시간 초과로 만료 처리 (배치 작업)
2. 재주문 안내

### "결제는 됐는데 티켓이 없어요"
1. 주문 완료 이벤트 처리 여부 확인
2. 주문 상태가 확정/승인 상태인지 확인
3. 발급 티켓 생성 여부 확인
