# EP09: 티켓 판매 시간 설정

> 상태: 🟡 ready | 우선순위: P1 | 스프린트: TBD

## 배경

현재 티켓 판매 시간은 **이벤트 단위**로만 제어됩니다:
- 이벤트 상태가 `OPEN`이면 판매 가능
- `event.startAt` 이후에는 자동으로 판매 불가

호스트가 "얼리버드 티켓은 3월 1일까지만, 일반 티켓은 공연 당일까지" 같은 **티켓별 판매 기간**을 설정할 수 없습니다.

## 목표

- 호스트가 **티켓 아이템별** 판매 시작/종료 시간을 설정할 수 있게 한다
- 판매 기간 외에는 해당 티켓을 구매할 수 없다
- **하위 호환성 100%**: 기존 티켓(시간 미설정)은 현재와 동일하게 동작

## 현재 코드 상태

### 이미 존재하는 필드 (미사용)

```kotlin
// TicketItem.kt
var saleStartAt: LocalDateTime? = null
var saleEndAt: LocalDateTime? = null
var isSellable: Boolean? = null
```

이 필드들이 DB 스키마에 존재하지만 **어디서도 검증하지 않습니다.**

### 현재 주문 검증 흐름

```
OrderValidator.validCanCreate(order)
  ├── validEventIsOpen(event)        // 이벤트 상태 OPEN 확인
  ├── validTicketingTime(event)      // NOW < event.startAt
  ├── validItemStockEnough(order)    // 재고 확인
  ├── validItemKindIsOneType(order)  // 단일 티켓 종류
  ├── validItemPurchaseLimit(order)  // 구매 제한
  └── validOptionNotChange(order)    // 옵션 변경 확인
```

여기에 **티켓별 판매 시간 검증**이 추가되어야 합니다.

## 설계

### 하위 호환성 원칙

| 필드 값 | 동작 |
|---------|------|
| `saleStartAt = null` | 제한 없음 (이벤트 OPEN부터 구매 가능) |
| `saleEndAt = null` | 제한 없음 (event.startAt까지 구매 가능) |
| `isSellable = null` 또는 `true` | 판매 가능 |
| `isSellable = false` | 수동 판매 중지 (시간 무관) |

**null = 제한 없음** → 기존 티켓은 아무것도 바뀌지 않음.

### 검증 로직 추가

```
OrderValidator.validCanCreate(order)
  ├── ... (기존 검증)
  ├── validTicketSaleTime(item)      // 🆕 추가
  │     ├── isSellable == false → 판매 중지됨 에러
  │     ├── saleStartAt != null && NOW < saleStartAt → 판매 시작 전 에러
  │     └── saleEndAt != null && NOW > saleEndAt → 판매 종료 에러
  └── ...
```

### 실제 판매 가능 시간 계산

```
판매 시작: max(이벤트 OPEN 시점, saleStartAt ?? 0)
판매 종료: min(event.startAt, saleEndAt ?? event.startAt)
```

### API 변경

#### 티켓 생성/수정 API (기존 확장)

```json
// POST /events/{eventId}/ticketItems
// 기존 필드 + 선택적 추가
{
  "name": "얼리버드",
  "quantity": 100,
  "saleStartAt": "2026-04-01T00:00:00",  // 선택 (null 허용)
  "saleEndAt": "2026-04-10T23:59:59",    // 선택 (null 허용)
  "isSellable": true                      // 선택 (기본값 true)
}
```

#### 티켓 목록 조회 응답 (기존 확장)

```json
{
  "ticketItemId": 1,
  "name": "얼리버드",
  "saleStartAt": "2026-04-01T00:00:00",
  "saleEndAt": "2026-04-10T23:59:59",
  "isSellable": true,
  "saleStatus": "ON_SALE"  // 🆕 계산 필드: BEFORE_SALE | ON_SALE | SALE_ENDED | STOPPED
}
```

#### 판매 수동 중지/재개 API (신규)

```
PATCH /events/{eventId}/ticketItems/{ticketItemId}/sale-status
Body: { "isSellable": false }
```

### 프론트엔드 변경

#### Admin App
- 티켓 생성 폼에 판매 시작/종료 DateTimePicker 추가 (선택 입력)

- 판매 중지/재개 토글 버튼

#### Ticket App (사용자)
- 판매 전 티켓: "X월 X일부터 구매 가능" 안내 표시, 구매 버튼 비활성화
- 판매 종료 티켓: "판매 종료" 표시, 구매 버튼 숨김
- 판매 중 티켓: 현재와 동일
