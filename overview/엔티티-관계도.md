# 엔티티 관계도

> DDD 아키텍처로 엔티티 간 직접 참조 없이 **ID 참조**만 사용합니다.

## 엔티티 관계 그래프


## 도메인별 Aggregate 정리

| Aggregate Root | 하위 엔티티 | ID 참조 대상 |
|----------------|------------|-------------|
| **User** | - | - |
| **Host** | HostUser | User |
| **Event** | EventDetailImage | Host |
| **TicketItem** | ItemOptionGroup | Event |
| **OptionGroup** | Option | Event |
| **Cart** | CartLineItem, CartOptionAnswer | User, TicketItem |
| **Order** | OrderLine, OrderOptionAnswer | User, Event |
| **IssuedTicket** | IssuedTicketOptionAnswer | User, Event, TicketItem, OrderLine |
| **CouponCampaign** | IssuedCoupon | User |
| **EventSettlement** | - | Event |
| **TransactionSettlement** | FeeDetail | Event |
| **Comment** | - | User, Event |
