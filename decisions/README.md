# 의사결정 로그 (Decision Log)

프로덕트/정책 결정 사항을 기록합니다.
결정의 맥락과 이유를 남겨서 나중에 "왜 이렇게 했지?" 할 때 찾을 수 있게 합니다.

## 포맷

```markdown
## DEC-001: 제목

- **일자**: 2026-03-15
- **결정**: (결정 내용)
- **이유**: (왜 이렇게 결정했는지)
- **대안**: (검토했지만 선택 안 한 것)
- **영향**: (이 결정에 영향받는 태스크)
- **참여자**: (결정에 참여한 사람)
```

## 미결 사항

- [ ] 공연 기본정보 등록 후 수정 허용 범위 (EP02-T06)
- [ ] 두둥 중개 수수료 정책 (현재 0원, settlement 도메인)
- [ ] MASTER 역할 이전 가능 여부 (host 도메인)
- [ ] OUTDATED 주문 결제 시간 초과 기준 (order 도메인)
- [ ] 탈퇴 유저 데이터 보관 기간 (user 도메인)
- [ ] 쿠폰 시스템 활성화 조건 (coupon 도메인)
