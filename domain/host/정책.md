# 호스트(Host) 도메인 정책

## 역할 체계 (HostRole)

| 역할 | 코드 | 권한 범위 |
|------|------|----------|
| 방장 | `MASTER` | 모든 권한 + 역할 변경 + 멤버 추방 |
| 매니저 | `MANAGER` | 이벤트 관리, 주문 승인/취소, 입장 처리, 초대 |
| 게스트 | `GUEST` | 조회만 가능 |

### 권한 계층
```
MASTER > MANAGER > GUEST
```

### 권한 검사
- `@HostRolesAllowed` AOP로 선언적 권한 검사
- `@HostPartnerAllowed` → 제휴 호스트 전용 기능 (유료 티켓 등)

## 호스트 생성 규칙

| 필드 | 필수 | 제약 |
|------|:----:|------|
| 이름 (name) | O | 최대 15자 |
| 소개 (introduce) | O | 최대 255자 |
| 연락처 이메일 | X | |
| 전화번호 | X | 최대 15자 |
| 프로필 이미지 | X | S3 이미지 |

- 생성자가 자동으로 **MASTER** 역할
- `master_user_id` 기록

## 멤버 관리 정책

### 초대
| 항목 | 내용 |
|------|------|
| 주체 | MANAGER 이상 |
| 동시성 | Redisson 분산락 |
| 검증 | 중복 가입 검증 (같은 user_id + host_id 불가) |
| 초기 상태 | `active = false` (초대 상태) |

### 초대 승락
| 항목 | 내용 |
|------|------|
| 주체 | 초대받은 본인 |
| 프로세스 | 2단계: 초대 → 본인 승락 (`active = true`) |

### 역할 변경
| 항목 | 내용 |
|------|------|
| 주체 | MASTER만 |
| 제약 | **MASTER 역할은 변경 불가** |

### 멤버 제거
| 항목 | 내용 |
|------|------|
| 주체 | MASTER만 |
| 프로세스 | **2단계**: 비활성화(`active = false`) 후 제거 |
| 제약 | 활성 멤버 직접 제거 불가 |

## 제휴 호스트 (Partner)

> 출처: [제휴 호스트](../public-notion/제휴-호스트.md)

### 제휴 호스트란?
`partner` 플래그가 `true`인 호스트로, 추가 기능을 사용할 수 있습니다.

### 제휴 전용 기능
| 기능 | 설명 |
|------|------|
| 카드 결제 | 유료 티켓(`PRICE_TICKET`) 생성 및 PG 결제 |
| 카카오톡 알림톡 | 예매 완료 시 카카오톡 채널 알림 발송 |

### 수수료
- 카드 결제 수수료 발생 (토스페이먼츠)
- 두둥 중개 수수료: 현재 0원 (정책 미확정)

### 제휴 문의
- 별도 연락 필요 (관리자 수동 설정)

## Slack 알림 정책

### 설정
- 호스트별 Slack 웹훅 URL **1개**
- 중복 URL 등록 차단

### 알림 종류 (10종)

| 카테고리 | 알림 |
|----------|------|
| 호스트 (4종) | 멤버 초대, 가입, 추방, 역할변경 |
| 주문 (6종) | 주문 생성, 승인, 거절, 취소, 환불, 입장 처리 |

### 구현 방식
- 도메인 이벤트(`Events.raise()`) → 인프라 핸들러 → Slack API
- 비즈니스 로직과 알림 로직 완전 분리
