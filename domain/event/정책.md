# 이벤트(Event) 도메인 정책

## 상태 머신

5개 상태, 4개 정방향 전이로 구성됩니다.

```
PREPARING ──(오픈)──► OPEN ──┬──(정산)──► CALCULATING ──(종료)──► CLOSED
                             │
                             └──(삭제)──► DELETED
```

| 상태 | 코드 | 설명 |
|------|------|------|
| 준비중 | `PREPARING` | 이벤트 생성 직후, 정보 입력 중 |
| 진행중 | `OPEN` | 티켓 판매 가능, 주문 수락 가능 |
| 정산중 | `CALCULATING` | 이벤트 종료 후 정산 처리 |
| 지난 공연 | `CLOSED` | 정산 완료 |
| 삭제됨 | `DELETED` | 소프트 삭제 (목록에서 자동 제외) |

---

## 이벤트 생성 규칙

### 필수 입력
- 소속 호스트
- 이벤트 이름 (최대 30자)
- 시작 일시
- 러닝타임 (분)

### 자동 계산
- 종료 시간 = 시작 시간 + 러닝타임

### 생성 권한
- 매니저 이상 권한이 필요합니다.

### 알림
- 이벤트 생성 시 Slack 알림이 발송됩니다.

---

## 오픈 조건 (준비중 → 진행중)

5가지 조건을 **모두** 만족해야 오픈 가능합니다.

| # | 조건 | 미충족 시 |
|---|------|----------|
| 1 | 기본 정보 등록 완료 (이름, 시간, 러닝타임) | 오픈 불가 |
| 2 | 장소 정보 등록 완료 | 오픈 불가 |
| 3 | 상세 설명 및 이미지 등록 완료 | 오픈 불가 |
| 4 | 티켓 최소 1개 등록 완료 | 오픈 불가 |
| 5 | 공연 시작 시간이 현재 시각 이후 | 오픈 불가 (시간 만료) |

- 오픈 권한: 매니저 이상

---

## 수정 규칙

### 준비중 상태
- **모든 정보** 수정 가능 (기본정보, 장소, 상세, 티켓)

### 진행중(오픈) 상태
- **기본 정보 수정 불가**: 이름, 시작시간, 러닝타임은 변경할 수 없습니다.
  - 이미 티켓을 구매한 관객에게 혼란을 주지 않기 위함입니다.
- **장소 정보 수정 불가**: 공연 장소도 변경할 수 없습니다.
- **상세 정보 수정 가능**: 공연 설명과 이미지는 수정할 수 있습니다.

### 정산중 / 종료 상태
- 모든 수정 불가

---

## 삭제 규칙

| 조건 | 결과 |
|------|------|
| 진행중 상태에서 삭제 시도 | 삭제 불가 (진행 중인 공연은 삭제할 수 없습니다) |
| 이미 삭제된 상태 | 삭제 불가 |
| 발급된 티켓이 존재 | 삭제 불가 |
| 준비중 상태이고 발급 티켓 없음 | 삭제 가능 |

- **방식**: 소프트 삭제 (실제 데이터는 유지, 목록에서만 제외)
- **알림**: 삭제 시 Slack 알림이 발송됩니다.
- **삭제 권한**: 매니저 이상

## 시간 검증

| 검증 항목 | 조건 |
|----------|------|
| 오픈 가능 여부 | 공연 시작 시간이 현재 시각 이후여야 합니다 |
| 티켓팅 가능 여부 | 현재 시각이 공연 시작 시간 이전이어야 합니다 |
| 환불 가능 여부 | 현재 시각이 공연 시작 시간 이전이어야 합니다 |

## 이벤트 구성 요소

이벤트는 아래 4가지 정보 묶음으로 구성됩니다.

| 구성 요소 | 포함 필드 |
|----------|----------|
| 기본 정보 | 이름, 시작 일시, 러닝타임, 종료 일시 |
| 장소 정보 | 장소명, 주소, 위도, 경도 |
| 상세 정보 | 공연 설명(본문) |
| 상세 이미지 | 이미지 (S3 저장) |
