# 댓글(Comment) 도메인 정책

## 기본 규칙

| 규칙 | 내용 |
|------|------|
| 작성 자격 | 로그인한 사용자만 작성 가능 |
| 귀속 단위 | 이벤트별로 관리 |
| 내용 제한 | 최대 **200자** |
| 닉네임 제한 | 최대 **15자** |
| 삭제 방식 | 소프트 삭제 (데이터는 유지, 비활성 처리) |
| 삭제 검증 | 해당 이벤트 소속 댓글인지 재검증, 이미 삭제된 댓글 이중 삭제 방지 |
| 특수 기능 | 랜덤 댓글 조회 (서비스 노출용) |

---

## 상태

```
활성(ACTIVE) ──(삭제)──► 비활성(INACTIVE) (되돌릴 수 없음)
```

---

## 댓글 관련 주요 기능

| 기능 | 권한 |
|------|------|
| 댓글 작성 | 로그인한 사용자 |
| 댓글 삭제 | 작성자 본인 |
| 랜덤 댓글 조회 | 누구나 (비로그인 포함) |
| 댓글 목록 조회 | 누구나 (비로그인 포함) |
