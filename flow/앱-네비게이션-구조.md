## 관객 앱 (ticket — dudoong.com)

### 하단 탭 바

```
┌──────────┬──────────┬──────────┬──────────┐
│   HOME   │ HOSTING  │  TICKET  │    MY    │
│   🏠     │   🎵     │   🎫     │   👤     │
└──────────┴──────────┴──────────┴──────────┘
```

| 탭 | 아이콘 | 진입 화면 | 주요 기능 |
|----|--------|---------|---------|
| HOME | 집 | 공연 목록 (#42) | 공연 탐색, 필터, 검색 |
| HOSTING | 음표 | 공연 준비 홈 | 호스트/공연 관리 (어드민 역할) |
| TICKET | 티켓 | 티켓 목록 (#49) | 예매 내역, 상태 확인 |
| MY | 사람 | 마이페이지 (#52) | 프로필, 관심 공연, 설정 |

### 화면 깊이 구조

```
HOME
├── 공연 목록 (#42)
│   ├── [필터] 태그 드롭다운 (#44)
│   └── 공연 상세 (#45 / #54)
│       ├── 문의처 팝업 (#57)
│       ├── 티켓 구매하기
│       │   ├── 옵션 선택 (#46)
│       │   ├── 결제하기 (#47 / #58 / #64)
│       │   └── 결제 완료 / 입금 안내 (#48)
│       └── [하트] 관심 공연 등록 (신규)
└── [검색] (화면 미확인)

HOSTING
├── 공연 준비 홈
│   ├── [탭] 등록한 공연 (empty / list)
│   └── [탭] 호스트 (empty / list)
├── 공연 상세 (호스트) — 필수 체크리스트
│   ├── 기본정보 입력 (190:7772)
│   ├── 상세정보 입력 (화면 미확인)
│   └── 티켓 관리 (262:3970)
└── + 공연 추가하기 / + 호스트 등록하기

TICKET
├── 티켓 목록 (#49)
│   └── 주문 상세 (#56 / #65)
└── [필터] 태그, 지난공연보기, 정렬

MY
├── 마이페이지 (#52)
│   ├── 내 공연 리스트
│   ├── 관심 공연 (신규)
│   ├── 구매 내역
│   ├── 호스트 관리
│   ├── 호스팅 공연 관리
│   ├── 서비스 업데이트 노트
│   ├── 계정 설정
│   ├── 로그아웃
│   └── 회원탈퇴
└── [알림] 🔔 (상단)
```

### 특이사항

- **HOSTING 탭이 관객 앱에 포함됨** — 현행 서비스는 admin.dudoong.com이 별도인데, v0.9 디자인에서는 하단탭으로 통합
- 이것이 의도된 변경인지 디자이너 확인 필요 (D7)
- 호스트 관리는 마이페이지에서도 진입 가능 (중복 경로)

## 호스트 어드민 앱 (admin — admin.dudoong.com)

> 현행 서비스 기준. Figma v0.9에서는 관객 앱과 통합 가능성 있음

### 사이드 네비게이션

```
호스트 목록 (/)
├── 호스트 생성 (/new/hosts)
├── 이벤트 생성 (/new/events)
│
├── 호스트 상세
│   ├── 대시보드  (/hosts/{id}/dashboard)
│   ├── 멤버 관리  (/hosts/{id}/member)
│   ├── 호스트 정보 (/hosts/{id}/info)
│   ├── 제휴 정보  (/hosts/{id}/alliance)
│   └── Slack 연동 (/hosts/{id}/slack)
│
└── 이벤트 상세
    ├── 대시보드    (/events/{id}/dashboard)
    ├── 상세 정보   (/events/{id}/detail)
    ├── 기본 정보   (/events/{id}/info)
    ├── 티켓 관리   (/events/{id}/tickets)
    ├── 옵션 관리   (/events/{id}/options)
    ├── 예매자 관리  (/events/{id}/guests)
    └── QR 스캐너   (/events/{id}/qr)
```
