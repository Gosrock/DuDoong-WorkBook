# 유저/인증(User) 도메인 정책

## 로그인/회원가입

### 카카오 OAuth (단일 인증 수단) — `KAKAO`
- 카카오(`KAKAO`) 로그인만 지원합니다.
- 카카오가 발급한 토큰의 서명을 서버에서 직접 검증하여 사용자를 식별합니다.
- 로그인과 회원가입 모두 동일한 검증 경로를 사용합니다.

### 회원가입 흐름

```
카카오 인증 → 신규 사용자 여부 확인
    ├── 기존 사용자 → 로그인 (토큰 발급)
    └── 신규 사용자 → 회원가입 폼 → 등록 → 토큰 발급
```

### 회원가입 입력 정보

| 필드 | 필수 | 비고 |
|------|:----:|------|
| 이름 | O | |
| 이메일 | O | |
| 전화번호 | X | |
| 프로필 이미지 | X | |
| 마케팅 동의 | X | 기본값: 미동의 |

- 동일 카카오 계정으로 동시에 가입 시도하는 경우를 차단합니다.

## 토큰 정책

### 토큰 구조

| 토큰 | 기본 유효 시간 | 저장 위치 |
|------|--------------|----------|
| Access Token | 1시간 | 쿠키 또는 Authorization 헤더 |
| Refresh Token | 1시간 | Redis (서버 측) |

### 토큰 추출 우선순위
1. 쿠키(`accessToken`) 우선 확인
2. `Authorization: Bearer` 헤더로 fallback

### 쿠키 보안 설정

| 설정 | 값 |
|------|---|
| Secure | 항상 활성화 |
| SameSite | 운영: Strict / 개발: None |
| HttpOnly | 미적용 (보안 이슈 참고) |

### 토큰 갱신
- Refresh Token으로 Access Token을 재발급합니다.
- 갱신 시 마지막 로그인 시각이 업데이트됩니다.

## 탈퇴 처리

### 처리 절차
1. **세션 무효화**: 서버에 저장된 Refresh Token 삭제
2. **계정 비활성화**: 계정 상태를 탈퇴로 변경, 개인정보 마스킹 처리
   - 이름 → "탈퇴한 유저"
   - 이메일, 전화번호, 프로필 이미지 → 삭제
   - 카카오 연동 식별자 변경 (재가입 대비)
3. **카카오 연결 해제**: 카카오 서비스와의 연동을 끊습니다.

### 탈퇴 시 주의사항
- 승인 대기 중인 주문이 있는 경우, 해당 주문은 자동으로 거절 처리됩니다.

## 인가 체계

### 시스템 역할 계층

```
최고 관리자(SUPER_ADMIN) > 관리자(ADMIN) > 매니저(MANAGER) > 일반 사용자(USER)
```

### API 접근 제어

| 분류 | 대상 |
|------|------|
| **인증 불필요** | 카카오 OAuth 로그인/회원가입, 토큰 갱신 |
| | 이벤트 상세 조회 (GET) |
| | 이벤트 검색, 댓글 조회 |
| **로그인 필요** | 나머지 모든 API |
| **최고 관리자 전용** | 쿠폰 캠페인 생성 |

### 호스트 도메인 이중 인가

시스템 역할 외에 **호스트 멤버 역할**이 별도로 적용됩니다.

```
방장 > 매니저 > 게스트
```

호스트 관련 API는 이 두 가지 인가 체계를 모두 통과해야 합니다.

## 알려진 보안 이슈

| 이슈 | 심각도 | 설명 |
|------|:------:|------|
| HttpOnly 쿠키 미적용 | 높음 | XSS 공격으로 토큰 탈취 가능성 있음 |
| Access/Refresh 유효 시간 동일 | 중간 | 기본값 둘 다 1시간, Refresh가 더 길어야 실용적 |
| 일시정지 상태 미구현 | 낮음 | 상태값만 존재, 실제 동작 없음 |
