## 설명
주문 거절된 티켓이 마이페이지에서 "승인 대기"로 표기됨

## 경로
마이페이지 > 내 티켓

## 작업 내용
- [ ] [BE] 주문 거절 시 티켓 상태 정확히 반환하는지 확인
- [ ] [FE] 마이페이지 티켓 상태 매핑 로직 수정

## 현재 구현 상태 (FE)
- 마이페이지 티켓 카드(`TicketItem`): 취소된 티켓은 `disabled` 처리 + "취소된 티켓" 텍스트
- 주문 상태 표시는 서버 응답 그대로 렌더링 → BE 응답이 잘못되면 FE도 잘못 표시
- **확인 필요**: BE에서 거절 주문의 티켓 상태가 어떻게 내려오는지 API 응답 확인

## 수락 기준

- [ ] 마이페이지 > 내 티켓에서 거절된 주문의 티켓이 "주문 취소"로 표시된다
- [ ] "승인 대기" 표시는 더 이상 거절 상태에 노출되지 않는다
- [ ] BE 응답의 티켓 상태값이 거절 케이스에서 올바른 값을 반환한다

## 참고
상태값 매핑 버그일 가능성 높음. BE 응답 먼저 확인 후 FE 수정 판단
