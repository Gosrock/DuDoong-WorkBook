## 설명

`OrderValidator.validCanCreate()`에 티켓별 판매 시간 검증 로직을 추가한다.
기존 `saleStartAt`, `saleEndAt`, `isSellable` 필드를 활성화하여 검증에 사용.

## 경로

- `DuDoong-Domain/.../order/domain/validator/OrderValidator.kt`
- `DuDoong-Domain/.../ticket_item/domain/TicketItem.kt`

## 작업 내용

- [ ] [BE] `TicketItem`에 판매 시간 검증 메서드 추가 (`validateSaleTime()`)
- [ ] [BE] `OrderValidator.validCanCreate()`에 `validTicketSaleTime(item)` 호출 추가
- [ ] [BE] 에러 코드 추가 (`Ticket_Item_400_10`, `_11`, `_12`)
- [ ] [BE] null 필드 = 제한 없음 (하위 호환)

## 수락 기준

- [ ] `saleStartAt`/`saleEndAt`이 null인 기존 티켓은 동작 변화 없음
- [ ] `saleStartAt` 이전에 주문 시도 → `Ticket_Item_400_10` 에러
- [ ] `saleEndAt` 이후에 주문 시도 → `Ticket_Item_400_11` 에러
- [ ] `isSellable = false`일 때 주문 시도 → `Ticket_Item_400_12` 에러
- [ ] E2E 테스트 기존 122개 통과
