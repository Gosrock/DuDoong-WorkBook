# 호스트(Host) 도메인 정책

## 역할 체계

| 역할 | 권한 범위 |
|------|----------|
| 방장 (MASTER) | 모든 권한 + 멤버 역할 변경 + 멤버 추방 |
| 매니저 (MANAGER) | 이벤트 관리, 주문 승인/취소, 입장 처리, 멤버 초대 |
| 게스트 (GUEST) | 조회만 가능 |

### 권한 계층
```
방장 > 매니저 > 게스트
```

- 호스트 관련 API는 역할 계층에 따라 접근이 제어됩니다.
- 제휴 호스트 전용 기능(유료 티켓 등)은 별도 제휴 여부를 확인합니다.

## 호스트 생성 규칙

| 필드 | 필수 | 제약 |
|------|:----:|------|
| 이름 | O | 최대 15자 |
| 소개 | O | 최대 255자 |
| 연락처 이메일 | X | |
| 전화번호 | X | 최대 15자 |
| 프로필 이미지 | X | |

- 호스트를 생성한 사용자가 자동으로 **방장** 역할을 부여받습니다.

---

## 멤버 관리 정책

### 초대
| 항목 | 내용 |
|------|------|
| 초대 권한 | 매니저 이상 |
| 중복 방지 | 동일 사용자를 같은 호스트에 중복 초대 불가 |
| 초대 직후 상태 | 비활성 (초대 수락 대기) |

### 초대 수락
- 초대받은 본인이 직접 수락해야 활성화됩니다.
- 초대 → 수락 2단계 프로세스로 진행됩니다.

### 역할 변경
- 방장만 멤버의 역할을 변경할 수 있습니다.
- 방장 역할 자체는 변경할 수 없습니다.

### 멤버 제거
- 방장만 멤버를 제거할 수 있습니다.
- 활성 멤버를 바로 제거할 수 없습니다. 비활성화 후 제거하는 2단계 프로세스로 진행됩니다.

## 제휴 호스트 (Partner)

> 출처: [제휴 호스트](../public-notion/제휴-호스트.md)

### 제휴 호스트란?
제휴 등록된 호스트로, 추가 기능을 사용할 수 있습니다.

### 제휴 전용 기능
| 기능 | 설명 |
|------|------|
| 카드 결제 | 유료 티켓 생성 및 PG 결제 가능 |
| 카카오톡 알림톡 | 예매 완료 시 카카오톡 채널 알림 발송 |

### 수수료
- 카드 결제 수수료 발생 (토스페이먼츠)
- 두둥 중개 수수료: 현재 0원 (정책 미확정)

### 제휴 문의
- 별도 연락 필요 (관리자 수동 설정)

|----------|------|
| 이벤트 | 생성, 수정, 삭제, 공개 |
| 주문 | 승인, 취소, 거절 |
| 입장 | QR 검증 |
| 멤버 | 초대 |
| 기타 | 이미지 업로드 |

## Slack 알림 정책

### 설정
- 호스트별 Slack 웹훅 URL 1개
- 중복 URL 등록 차단

### 알림 종류 (10종)

| 카테고리 | 알림 |
|----------|------|
| 멤버 관련 (4종) | 멤버 초대, 가입, 추방, 역할 변경 |
| 주문 관련 (6종) | 주문 생성, 승인, 거절, 취소, 환불, 입장 처리 |

- 알림은 비즈니스 로직과 완전히 분리되어 비동기로 처리됩니다.
