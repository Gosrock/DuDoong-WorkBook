# EP05 — 어드민 v2 기능 고도화

> 내부 운영 어드민(DuDoong-Admin-Front + DuDoong-Admin 모듈)의 기능을 확장하여
> 실제 운영에 필요한 조회/관리 기능을 제공한다.

---

## 배경

- 기존 어드민(DuDoong-Front/apps/admin)은 호스트 운영자 도구 → 새 어드민은 **플랫폼 관리자** 도구
- 현재는 기본 CRUD만 있고, 운영 시 자주 필요한 필터링/연결/호스트 관리가 부족
- 주요 문의: 호스트 유저 권한 변경, 이벤트별 주문 조회

## 원칙

- **어드민 밸리데이션 완화**: 일반 API의 상태 체크/권한 체크를 어드민에서는 우회 가능하게
  - 예: OPEN 이벤트도 어드민이면 삭제(soft delete) 가능
- **플랫폼 관리자 관점**: 호스트/이벤트/주문을 전체적으로 조회하고 관리

---

| ID | 태스크 | 파트 | 설명 |
