# 이벤트(Event) 도메인 정책

## 상태 머신

5개 상태, 4개 정방향 전이로 구성됩니다.

```
PREPARING ──(오픈)──► OPEN ──┬──(정산)──► CALCULATING ──(종료)──► CLOSED
                             │
                             └──(삭제)──► DELETED
```

| 상태 | 코드 | 설명 |
|------|------|------|
| 준비중 | `PREPARING` | 이벤트 생성 직후, 정보 입력 중 |
| 진행중 | `OPEN` | 티켓 판매 가능, 주문 수락 가능 |
| 정산중 | `CALCULATING` | 이벤트 종료 후 정산 처리 |
| 지난 공연 | `CLOSED` | 정산 완료 |
| 삭제됨 | `DELETED` | 소프트 삭제 |

> `@Where(clause = "status != 'DELETED'")` 적용으로 기본 쿼리에서 삭제된 이벤트 자동 제외

---

## UseCase 목록

| UseCase | 설명 | 권한 |
|---------|------|------|
| `CreateEventUseCase` | 이벤트 생성 | MANAGER 이상 |
| `UpdateEventUseCase` | 이벤트 수정 | MANAGER 이상 |
| `OpenEventUseCase` | 이벤트 오픈 (PREPARING → OPEN) | MANAGER 이상 |
| `CalculateEventUseCase` | 정산 시작 (OPEN → CALCULATING) | MANAGER 이상 |
| `CloseEventUseCase` | 이벤트 종료 (CALCULATING → CLOSED) | MANAGER 이상 |
| `DeleteEventUseCase` | 이벤트 삭제 (→ DELETED) | MANAGER 이상 |

---

## 생성 규칙

### 필수 입력
- `hostId`: 소속 호스트 ID
- `name`: 이벤트 이름 (최대 30자)
- `startAt`: 시작 일시
- `runTime`: 러닝타임 (분)

### 자동 계산
- `endAt = startAt + runTime`

### 도메인 이벤트
- `EventCreationEvent` 발행 → Slack 알림

---

## 오픈 조건 (PREPARING → OPEN)

5가지 조건을 **모두** 만족해야 오픈 가능합니다:

| # | 조건 | 미충족 시 |
|---|------|----------|
| 1 | EventBasic 존재 (이름, 시간, 러닝타임) | 오픈 불가 |
| 2 | EventPlace 존재 (장소) | 오픈 불가 |
| 3 | EventDetail 존재 (상세 설명/이미지) | 오픈 불가 |
| 4 | TicketItem 최소 1개 존재 | 오픈 불가 |
| 5 | startAt이 현재시간 이후 | `EventOpenTimeExpiredException` |

---

## 수정 규칙

### PREPARING 상태
- **모든 정보** 수정 가능 (기본정보, 장소, 상세, 티켓)

### OPEN 상태
- 기본 정보 수정 **불가** → `CannotModifyOpenEventException`
  - 이름, 시작시간, 러닝타임
- 장소 정보 수정 **불가** → `CannotModifyOpenEventException`
- 상세 정보 수정 **가능**
  - 설명(content), 이미지

### CALCULATING / CLOSED 상태
- 수정 불가

---

## 삭제 규칙

| 조건 | 결과 |
|------|------|
| OPEN 상태에서 삭제 시도 | `CannotDeleteByOpenEventException` |
| 이미 DELETED 상태 | `AlreadyDeletedStatusException` |
| 발급 티켓 존재 | 삭제 불가 |
| PREPARING 상태 (티켓 없음) | 삭제 가능 (→ DELETED) |

- **방식**: Soft delete (`status = DELETED`)
- **도메인 이벤트**: `EventDeletionEvent` 발행

---

## 시간 검증

| 검증 | 조건 | 예외 |
|------|------|------|
| 오픈 가능 시간 | `startAt > now()` | `EventOpenTimeExpiredException` |
| 티켓팅 가능 시간 | `now() < startAt` | `EventTicketingTimeIsPassedException` |
| 환불 가능 기간 | `now() < startAt` | 환불 불가 |

## 도메인 이벤트

| 이벤트 | 발행 시점 | 처리 |
|--------|----------|------|
| `EventCreationEvent` | 이벤트 생성 시 | Slack 알림 |
| `EventStatusChangeEvent` | 상태 변경 시 | Slack 알림 |
| `EventContentChangeEvent` | 내용 수정 시 | Slack 알림 |
| `EventDeletionEvent` | 삭제 시 | Slack 알림 |

---

## 값 객체 (Value Objects)

| VO | 필드 | 용도 |
|----|------|------|
| `EventBasic` | name, startAt, runTime, endAt | 기본 정보 |
| `EventPlace` | placeName, placeAddress, latitude, longitude | 장소 정보 |
| `EventDetail` | content | 상세 정보 |
| `EventDetailImage` | imageKey | 이미지 (S3) |
