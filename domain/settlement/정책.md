# 정산(Settlement) 도메인 정책

## 정산 구조

```
이벤트 단위 정산
    └── 거래 단위 정산
            └── 수수료 상세
```

---

## 정산 상태 머신

```
정산 대기 ──► 계산 완료 ──► 관리자 확인 ──► 호스트 확인
```

| 상태 | 설명 |
|------|------|
| 정산 대기 | 이벤트 종료 후 초기 상태 |
| 계산 완료 | 정산 금액 자동 계산 완료 |
| 관리자 확인 | 두둥 운영팀 확인 완료 |
| 호스트 확인 | 호스트(주최자)가 최종 확인 완료 |

---

## 정산 금액 계산

```
총 매출       = 두둥티켓 승인 완료 주문 + 카드결제 완료 주문

수수료        = PG 수수료 (토스페이먼츠) + VAT (PG 수수료 × 10%)

두둥 중개 수수료 = 현재 0원 (정책 미확정)

정산 금액     = 총 매출 - 수수료 - 두둥 수수료
```

---

## 정산 프로세스

> 출처: [두둥 정산 관련](../public-notion/두둥-정산-관련.md)

1. 이벤트 종료 후 **자동으로** 정산 작업이 시작됩니다.
2. 호스트 방장의 이메일로 **정산서가 전송**됩니다.
3. 호스트 방장이 정산서를 확인하고 응답합니다.
4. 세금 계산서 발행을 위해 대표자 **통장 사본 제출**이 요청됩니다.
5. 공연 종료 **6일 이후** 정산 금액이 지급됩니다 (일정이 앞당겨질 수 있습니다).
6. 세금 계산서가 발행됩니다.

---

## 정산 부속 자료

- 주문 목록 엑셀 파일이 자동으로 생성되어 정산 기록에 첨부됩니다.

---

## 경쟁 서비스 비교 (노션 참조)

- 와디즈, 페스타, 텀블벅 등과 비교 자료가 존재합니다.

---

## 문의 대응 가이드

### "정산이 언제 되나요?"
- 공연 종료 6일 이후 지급됩니다.
- 정산 진행 단계: 정산 대기 → 계산 완료 → 관리자 확인 → 호스트 확인

### "정산 금액이 이상해요"
- PG 수수료와 부가세(VAT)가 차감됩니다.
- 환불/취소된 주문은 정산에서 제외됩니다.
