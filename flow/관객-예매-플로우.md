# 관객 예매 플로우

## 1. 인증 (카카오 로그인)

사용자가 카카오 로그인 버튼을 누르면 카카오 인증 화면으로 이동한다.
인증 완료 후 신규 여부에 따라 회원가입 또는 로그인 처리된다.

```
카카오 로그인 버튼
  → GET /auth/oauth/kakao/link (인증 URL 획득)
  → 카카오 인증 완료
  → GET /auth/oauth/kakao?code={code} (토큰 교환)
  → 신규 여부 확인
      ├── 신규 → POST /auth/oauth/kakao/register (회원가입)
      └── 기존 → POST /auth/oauth/kakao/login (로그인)
  → 인증 상태 업데이트 + 쿠키 저장
```

### 실패 분기

| 상황 | 사용자에게 보이는 것 | 처리 |
|------|------------------|------|
| 카카오 인증 취소/실패 | "로그인에 실패했습니다. 다시 시도해 주세요." | 로그인 화면으로 복귀, 재시도 버튼 제공 |
| 네트워크 오류 | "일시적인 오류가 발생했습니다." | 로그인 화면으로 복귀 |
| 토큰 교환 실패 | "인증 처리 중 오류가 발생했습니다." | 로그인 화면으로 복귀 |

## 2. 이벤트 탐색 & 예매

홈 화면에서 이벤트를 검색하거나 목록을 탐색한다.
이벤트 상세에서 티켓을 선택하고, 로그인된 경우 예매를 진행한다.
로그인이 되어 있지 않으면 로그인 화면으로 이동한다.

```
/home                      → 이벤트 목록 (검색/필터)
  ↓
/events/{eventId}          → 이벤트 상세 + 티켓 선택
  ↓  (로그인 필요)
/events/{eventId}/book/option  → 옵션 선택 (없으면 자동 스킵)
  ↓  POST /carts (장바구니 생성 → cartId)
/events/{eventId}/book/order   → 주문 확인 + 결제 방식 선택
```

### 실패 분기

| 상황 | 사용자에게 보이는 것 | 처리 |
|------|------------------|------|
| 로그인 안 된 상태에서 예매 시도 | 로그인 화면으로 이동 | 로그인 완료 후 예매 화면으로 복귀 |
| 매진된 티켓 선택 | "해당 티켓은 매진되었습니다." | 다른 티켓 선택 유도 (EP01-T02 연결) |
| 판매 기간 외 접근 | "판매 기간이 아닙니다." | 이벤트 상세 화면에서 안내 |
| 장바구니 생성 실패 | "잠시 후 다시 시도해 주세요." | 티켓 선택 화면으로 복귀 |

## 3. 결제 분기

### 유료 티켓 (PRICE_TICKET)

TossPayments 결제창이 열리고, 결제 완료 후 주문이 확정된다.

```
TossPayments SDK 결제창 열림
  → 결제 완료
  → /pay/confirm
  → POST /orders/{uuid}/confirm
  → /pay/success (예매 완료 안내)
```

**실패 분기**

| 상황 | 사용자에게 보이는 것 | 처리 |
|------|------------------|------|
| 결제 취소 (사용자가 닫음) | "결제가 취소되었습니다." | 공연 상세 화면으로 복귀 (EP01-T03 연결) |
| 결제 실패 (카드 한도 초과 등) | "결제에 실패했습니다. 결제 수단을 확인해 주세요." | 공연 상세 화면으로 복귀 (EP01-T03 연결) |
| 결제 시간 초과 | 주문이 OUTDATED 상태로 전환 | "결제 시간이 초과되었습니다." 안내 후 공연 상세로 복귀 |
| 서버 확인 실패 | "결제 확인 중 오류가 발생했습니다." | 고객센터 문의 안내, 결제 취소 처리 |

### 두둥 티켓 (DUDOONG_TICKET)

무통장입금 계좌 정보가 화면에 표시된다. 입금 후 호스트가 수동으로 승인하면 티켓이 발급된다.

```
무통장입금 계좌 안내 표시
  → POST /orders/ (주문 생성, 승인 대기 상태)
  → 호스트 승인 대기
  → 호스트 승인 → 티켓 발급
  → 호스트 거절 → 예매 취소 안내
```

**실패 분기**

| 상황 | 사용자에게 보이는 것 | 처리 |
|------|------------------|------|
| 호스트 승인 거절 | "호스트가 예매를 거절했습니다." | 예매 목록에서 상태 확인 가능 |
| 입금 기한 초과 | "입금 기한이 지나 예매가 취소되었습니다." | 예매 취소 안내 |

### 무료 티켓 (FREE_TICKET + 선착순)

별도 결제 없이 즉시 예매가 확정된다.

```
POST /orders/{uuid}/free
  → 즉시 확정
  → /pay/success (예매 완료 안내)
```

**실패 분기**

| 상황 | 사용자에게 보이는 것 | 처리 |
|------|------------------|------|
| 선착순 마감 (동시 접근) | "죄송합니다. 예매가 마감되었습니다." | 이벤트 상세 화면으로 복귀 (EP01-T02 연결) |

## 4. 예매 확인 & QR 입장

예매 완료 후 예매 목록에서 티켓을 확인하고, QR 코드로 입장한다.

```
/history                   → 예매 목록 조회
/history/{orderId}         → 주문별 티켓 목록
/ticket/{id}               → 개별 티켓 상세
                           → QR 코드 표시 (UUID 기반)
                           → 입장 상태별 표시:
                              - 입장 전: 검정
                              - 입장 완료: 회색
```

### 실패 분기

| 상황 | 사용자에게 보이는 것 | 처리 |
|------|------------------|------|
| QR 인식 실패 (스캐너 측) | 호스트 화면에 "인식 실패" 표시 | 재시도 버튼 제공, 또는 UUID 직접 입력으로 수동 입장 처리 |
| 이미 입장한 티켓 재스캔 | 호스트 화면에 "이미 입장한 티켓" 표시 | 입장 처리 없이 경고 안내 |
| 취소된 티켓 스캔 | 호스트 화면에 "취소된 티켓" 표시 | 입장 불가 안내 |
| 티켓 로딩 실패 | "티켓 정보를 불러올 수 없습니다." | 새로고침 안내 |
