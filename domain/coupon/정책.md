# 쿠폰(Coupon) 도메인 정책

> 현재 프로덕션에서 쿠폰 캠페인 **0건** (기능 구현 완료, 미사용 상태)

## 할인 유형

| 유형 | 설명 |
|------|------|
| 정액 할인 | 고정 금액만큼 할인 |
| 정률 할인 | 주문 금액의 일정 비율 할인 (최대 100%) |

## 적용 대상

| 대상 | 설명 |
|------|------|
| 전체 | 모든 이벤트에 사용 가능 (기본값) |
| 특정 이벤트 | 지정된 이벤트에만 사용 가능 |

---

## 발급 규칙

### 3중 제약
1. **발급 기간**: 설정된 발급 기간 내에서만 발급 가능
2. **재고**: 발급 수량 한도 내에서만 발급 가능
3. **유효 기간**: 발급일로부터 N일간 유효

### 동시성 제어
- 동시에 여러 사람이 쿠폰을 발급받을 때 중복 발급을 방지합니다.
- 1인 1쿠폰 원칙이 적용됩니다.

### 기타 규칙
- 쿠폰 코드는 시스템 전체에서 유일합니다.
- **최소 주문 금액**: 기본값 10,000원. 할인액이 최소 주문 금액을 초과하면 적용 불가합니다.
- 쿠폰 캠페인은 **최고 관리자(SUPER_ADMIN)만** 생성할 수 있습니다.

---

## 쿠폰 사용/복구

| 시점 | 동작 |
|------|------|
| 주문 생성 시 쿠폰 적용 | 쿠폰이 사용 처리되어 재사용 불가 상태로 변경 |
| 주문 취소/환불 시 | 쿠폰이 자동으로 복구되어 다시 사용 가능 상태로 변경 |

### 적용 가능 조건
- 선착순 방식의 주문에만 적용 가능합니다 (승인형 주문에는 사용 불가).
- 결제가 필요한 주문(유료)에만 적용 가능합니다.
- 최소 주문 금액 조건을 충족해야 합니다.

---

## 쿠폰 관련 주요 기능

| 기능 | 권한 |
|------|------|
| 쿠폰 캠페인 생성 | 최고 관리자 전용 |
| 쿠폰 발급 | 로그인한 사용자 |
| 사용 가능 쿠폰 조회 | 로그인한 사용자 |
