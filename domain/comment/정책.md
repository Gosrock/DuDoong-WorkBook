# 댓글(Comment) 도메인 정책

## 기본 규칙

| 규칙 | 내용 |
|------|------|
| 작성 자격 | 인증된 유저만 |
| 귀속 단위 | 이벤트별 |
| 내용 제한 | 최대 **200자** |
| 닉네임 제한 | 최대 **15자** |
| 삭제 방식 | 소프트 삭제 (`ACTIVE` → `INACTIVE`) |
| 삭제 검증 | 이벤트 소속 여부 재검증, 이중 삭제 방지 |
| 특수 기능 | 랜덤 댓글 조회 (`RetrieveRandomCommentUseCase`) |

---

## 상태

```
ACTIVE ──(삭제)──► INACTIVE (불가역)
```

---

## UseCase

| UseCase | 설명 | 권한 |
|---------|------|------|
| `CreateCommentUseCase` | 댓글 작성 | USER 이상 |
| `DeleteCommentUseCase` | 댓글 삭제 | 작성자 본인 |
| `RetrieveRandomCommentUseCase` | 랜덤 댓글 조회 | 공개 |
| `ReadCommentsUseCase` | 댓글 목록 조회 | 공개 |
