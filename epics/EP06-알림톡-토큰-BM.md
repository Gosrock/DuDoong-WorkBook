# EP06: 알림톡 토큰 BM

## 개요

호스트가 토큰을 충전하고, 카카오 알림톡을 자유롭게 사용하는 수익화 모델.
PG 없이 계좌이체로 충전, NCP 알림톡으로 발송. 두둥의 첫 번째 매출 채널.

## 배경

- 현재 두둥 매출: **0원** (중개 수수료 미확정, 제휴 호스트 알림톡은 무료 제공 중)
- 알림톡 인프라 이미 완성 (NcpHelper, 템플릿 3종, 이벤트 핸들러)
- 현재 제휴 호스트(`partner=true`)만 알림톡 사용 가능
- NCP 알림톡 원가: 건당 ~8원
- 호스트 1,171개, 이벤트 1,408개 — 잠재 고객 충분

## 토큰 충전 패키지

| 패키지 | 토큰 | 가격 | 건당 단가 |
|--------|------|------|----------|
| 베이직 | 100 | 5,000원 | 50원 |
| 프로 | 500 | 20,000원 | 40원 |

- 결제 방식: 계좌이체 → 관리자 확인 → 토큰 충전
- 마진율: 80~87% (원가 건당 ~8원)

## 토큰 소비 메뉴

| 기능 | 방향 | 설명 | 토큰 |
|------|------|------|------|
| 예매 완료 알림 | →관객 | 예매 확정 시 관객에게 카톡 | 1토큰/건 |
| 예매 취소 알림 | →관객 | 환불/취소 시 관객에게 카톡 | 1토큰/건 |
| 공지 발송 | →관객 | 호스트가 자유 내용 작성해서 관객에게 발송 | 1토큰/건 |
| 공연 홍보 | →이전 관객 | 이전 공연 관객에게 새 공연 안내 | 1토큰/건 |
| 예매/환불 접수 알림 | →호스트 | 예매 또는 환불 발생 시 호스트에게 카톡 | 1토큰/건 |

### 기능 상세

#### 관객 → 예매 완료/취소 알림 (기존 기능 확장)
- 현재: `host.isPartnerHost()` 체크 → 제휴 호스트만 발송
- 변경: `host.hasTokens() && eventSetting.enabled` → 토큰 있고 설정 켜져 있으면 발송
- 기존 NCP 템플릿 `doneorderv2`, `cancelorder` 그대로 사용

#### 관객 → 공지 발송 (신규)
- 호스트가 자유 내용 작성 → 해당 공연 예매 관객에게 일괄 발송
- NCP 템플릿: 변수형 범용 공지 템플릿 신규 등록 필요
- 템플릿 예시: `[#{호스트이름}] 공지\n#{자유내용}\n공연: #{공연이름}\n📅 #{날짜}`
- 용도: 장소 변경, 시간 변경, 리마인더, 안내사항 등 호스트 자유

#### 이전 관객 → 공연 홍보 (신규)
- 해당 호스트의 과거 공연 예매 관객에게 새 공연 안내
- 대상 자동 추출: 호스트의 이전 이벤트 → 확정 주문 → 유저 → 전화번호
- 발송 전 대상 수 + 필요 토큰 미리보기 제공
- NCP 템플릿: 홍보용 신규 등록 필요

#### 호스트 → 예매/환불 접수 알림 (신규)
- 예매 또는 환불 발생 시 호스트 멤버에게 카톡
- 호스트가 받을 사람 선택 가능 (방장, 매니저 등)
- 받는 사람 수 × 1토큰 소비
- NCP 템플릿: 접수 알림용 신규 등록 필요

## 운영 플로우

```
충전: 호스트 → 계좌이체 → 관리자 확인 → 토큰 충전
사용(자동): 호스트가 공연별 알림 ON → 이벤트 발생 시 자동 차감
사용(수동): 호스트가 공지/홍보 작성 → 대상 확인 → 발송 → 차감
잔액 부족: 발송 스킵 + Slack 웹훅으로 호스트에게 안내 (무료)
```

## 데이터 모델 (신규)

```
Host (기존 테이블 확장)
  └── tokenBalance: Long          ← 현재 잔액

TokenTransaction (신규)
  ├── id, hostId
  ├── type: CHARGE | CONSUME | REFUND
  ├── amount: Int                 ← +100 / -1
  ├── balance: Int                ← 거래 후 잔액
  ├── description: String
  ├── relatedEventId: Long?
  └── createdAt, createdBy

EventAlimTalkSetting (신규)
  ├── eventId
  ├── doneOrderEnabled: Boolean   ← 예매 완료 알림
  ├── withdrawOrderEnabled: Boolean ← 예매 취소 알림
  └── hostNotifyEnabled: Boolean  ← 예매/환불 접수 알림 (호스트)
```

## NCP 템플릿 작업

| 템플릿 | 상태 | 용도 |
|--------|------|------|
| `doneorderv2` | 기존 등록 완료 | 예매 완료 알림 |
| `cancelorder` | 기존 등록 완료 | 예매 취소 알림 |
| `settlement` | 기존 등록 완료 | 정산서 발송 |
| `hostnotice` | **신규 등록 필요** | 공지 발송 (변수형) |
| `promotion` | **신규 등록 필요** | 공연 홍보 |
| `hostnotify` | **신규 등록 필요** | 예매/환불 접수 알림 (호스트) |

## 의사결정 기록

| 결정 | 내용 | 이유 |
|------|------|------|
| PG 없이 계좌이체 | 토큰 충전은 계좌이체 + 관리자 수동 확인 | PG 수수료 회피, 운영 초기 규모에 적합 |
| 1토큰 = 1건 통일 | 모든 알림톡 1건당 1토큰 | 단순함, 호스트가 계산하기 쉬움 |
| 공지 발송은 변수형 템플릿 | 카카오 심사된 템플릿 + 자유 내용 변수 | 호스트 자유도 확보 + 카카오 정책 준수 |
| D-1 리마인더 별도 기능 제외 | 공지 발송으로 흡수 | 배치잡 정액 과금이 애매, 공지로 같은 효과 |
| 관객 수신거부 기능 제외 | 초기 버전에서 제외 | 단순화 우선, 필요 시 추후 추가 |
